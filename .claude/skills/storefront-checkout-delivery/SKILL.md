# Storefront, checkout & delivery

## Platform picker (verify current pricing/fees before recommending)
| Platform | Strengths | Watch-outs |
|---|---|---|
| Stan Store | link-in-bio native, mobile checkout, courses, bumps, email collection — creators love it | less design control |
| Gumroad | simple, global, acts as merchant of record (handles sales tax/VAT) | higher % fees, basic pages |
| Lemon Squeezy | merchant of record, licenses, affiliates, good checkout | more setup |
| Payhip | low cost, EU VAT handling, coupons, affiliates | basic design |
| Shopify + digital downloads app | if creator already has merch store | apps needed |
| Kajabi / Podia / Teachable / Thinkific | courses + email + funnels | monthly cost |
| ThriveCart / SamCart + custom page | advanced bumps/upsells, A/B testing | separate delivery |
Merchant-of-record platforms reduce tax compliance burden for global sales — important for creators without an accountant.

## Setup checklist
- [ ] Product(s), tiers, prices, currency; compare-at price only if honest
- [ ] Order bump + one-click upsell configured and tested
- [ ] Discount codes: early-bird, per-channel codes (IG, TikTok, email, ads) for attribution
- [ ] Affiliate program (optional): commission 30–50% for digital, cookie length, payout terms
- [ ] Delivery: file attached/hosted (PDF), course access, template links; delivery email in creator voice with access instructions + support email + "tag me when you start" CTA
- [ ] Post-purchase page: thank-you, upsell or "share on story" prompt, community link
- [ ] Refund policy configured; terms/privacy pages
- [ ] Email provider integration (Kit/ConvertKit, Klaviyo, Beehiiv, Flodesk) with buyer tag
- [ ] Pixels and conversion events firing; test with a 100% discount code then a real low-price purchase
- [ ] Payouts set to the correct account(s); revenue split method agreed (platform split payments, or monthly report + invoice)

## Revenue split reporting
Export orders weekly: gross, fees, refunds, net, split per partner; share a simple dashboard (see launch-metrics-and-reporting).
