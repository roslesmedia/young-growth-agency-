# Sales page copy & build

Most creator traffic is **mobile from Instagram/TikTok in-app browsers** → fast, thumb-friendly, CTA visible early and often.

## Section order (long-form, $27–$497 products)
1. **Hero**: outcome headline (audience language) + subhead (who it's for + timeframe + objection killer) + mockup + CTA button + micro-proof (★ rating / "2,300+ sold" — only if true).
2. **Problem/agitation**: "If you're…" bullets in their words.
3. **The shift / why other things failed**: introduce the creator's method.
4. **Meet the creator**: photo, credibility, story, results.
5. **What's inside**: modules/chapters as benefit bullets + page/lesson previews.
6. **Bonuses** with values.
7. **Testimonials/results** (screenshots, video, before/after) — near CTAs.
8. **Who it's for / not for**.
9. **Value stack + price** (tiers if applicable) + guarantee + CTA.
10. **FAQ** answering objections (time, level, format, access, refunds, devices).
11. **Final CTA** with recap + deadline (if real).
Short-form (< $20): hero → inside → proof → price → FAQ.

## Copy rules
Benefit > feature ("Hit your protein in 15 minutes a day" not "50 recipes"); specificity; one reader ("you"); creator voice; scannable bullets; CTA text = outcome ("Get the playbook →"). See direct-response-copywriting and hooks-and-headlines.

## Build options
- Store-native page (Stan/Gumroad/Kajabi) — fastest, checkout built in.
- Custom page (HTML/Next.js/Framer/Webflow) linking to checkout — best design control; for premium launches use the animated-site skills (award-site-architecture) but keep it fast on mobile in-app browsers (lazy-load heavy effects, LCP < 2.5s).
Design always from the creator's brand kit.

## Must-haves
Sticky mobile CTA bar, checkout in ≤ 2 taps, pricing visible without hunting, Meta Pixel/TikTok Pixel + GA4 events (view, initiate checkout, purchase), UTMs on every link from socials, countdown only for real deadlines, legal links (privacy, terms, refund).

## Test
Load on iPhone via IG in-app browser, check speed, test purchase, check emails. A/B test headline and hero after launch traffic is steady.
