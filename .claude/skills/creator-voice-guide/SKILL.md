# Creator voice guide

## Collect samples
- 20+ captions, 5–10 video transcripts (YouTube auto-captions, TikTok/IG transcripts, or have the creator send voice notes), newsletters, comment replies, podcast clips.
- Ask: "How would you explain <core topic> to a friend?" — record a 5-minute voice note.

## Analyze
| Dimension | Capture |
|---|---|
| Tone sliders | formal↔casual, serious↔playful, gentle↔tough-love, hype↔calm (1–10 each) |
| Sentence shape | short punchy / long storytelling; use of fragments; questions |
| Vocabulary | signature words, slang, emojis, swear words (yes/no), words they never use |
| Openers & sign-offs | "Okay so…", "Hey besties", "Let's get into it", "You've got this" |
| Teaching style | step-by-step, story-first, myth-busting, data-driven, personal anecdotes |
| Point of view | "I"/"you"/"we"; how they refer to audience (fam, girlies, friends, builders) |
| Beliefs/stances | strong opinions they repeat (great for hooks and sales page "enemy") |

## Output (`05-voice-guide.md`)
```
Voice in 3 words: ...
Do: ... | Don't: ...
Signature phrases: ...
Before/after example: generic sentence → rewritten in creator voice (5 pairs)
Formatting: emoji usage, caps, line breaks
```
Every piece of copy gets a final "voice pass": read it aloud as the creator; remove AI-sounding filler ("delve", "unlock", "elevate", "in today's fast-paced world", em-dash overuse). The creator approves the first chapter and first email before bulk writing. (The account-level Brand Voice plugin can enforce this guide across chats.)
