# Workbooks, planners & printables

## Decide the product shape
- **Workbook**: companion to a method — lessons + exercises + reflection prompts.
- **Planner**: date-based (yearly/monthly/weekly/daily) or undated; niche-specific pages (meal planner, workout log, budget tracker, content calendar, wedding planner, study planner, self-care journal).
- **Printables pack**: single-page tools (checklists, trackers, cards).
- **Digital planner**: landscape/tablet-sized PDF with hyperlinked tabs for GoodNotes/Notability.

## Page-type library (choose per niche)
Year at a glance • monthly calendar • weekly spread • daily page • habit tracker (grid 31 days × habits) • goal-setting (vision → goals → milestones → actions) • reflection prompts • budget/expense table • meal plan + grocery list • workout log (sets/reps/weight) • content calendar • mood tracker • gratitude log • notes (lined/dot grid) • progress photos/measurements.

## Layout rules
- Generous writing space: lined rows ~8–9mm (≈ 0.33in) apart for handwriting; dot grid 5mm.
- Lines/grids light (20–35% ink tint) so handwriting stands out; key labels in the creator's brand color.
- Printable versions: white backgrounds, no heavy fills (ink cost), safe margins ≥ 0.5in, offer Letter and A4.
- Digital planner: page size like 2224×1668 px (iPad landscape) or 1668×2224; tabs/side nav as `<a href="#jan">` internal links on every page; test links in a PDF viewer.
- Undated beats dated for evergreen sales (no expiry).

## Build
Generate repetitive pages programmatically (loop over months/days in JS or a build script producing HTML), styled from the creator's brand tokens and niche mood; export with html-render-pdf-png. Keep file size reasonable.

## Deliver
PDF(s) + quick "how to use" page (printing tips, how to import to GoodNotes). Mockups showing it on an iPad and printed on a desk sell this category.
