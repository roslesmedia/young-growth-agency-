# Template products

## Pick the template type for the niche
| Niche | Template ideas |
|---|---|
| Productivity / students | Notion life OS, study planner, habit tracker |
| Business / creators | content calendar (Notion/Sheets), Canva post templates, brand kit templates, pitch deck, media kit, email swipe file, hook bank |
| Finance | budget spreadsheet, debt payoff calculator, net worth tracker |
| Fitness / nutrition | workout program sheet with progression formulas, macro calculator, meal planner |
| Photography / editing | Lightroom presets, LUTs, CapCut templates |
| Career | resume templates, cover letter swipe file, interview prep Notion |

## Build guidance
- **Notion**: clean structure (dashboard → databases → views), relations/rollups only where useful, cover images + icons in creator's style, instructions toggle on each page; share as public "Duplicate" link (Notion template link). Test duplicating into a fresh account.
- **Canva**: build in Canva (Canva plugin/MCP if connected), share as "Template link" (not edit link). Use creator's fonts/colors; include 20–60 designs with variety; organize pages by use.
- **Google Sheets**: protected formula cells, input cells highlighted, dropdowns via data validation, conditional formatting, charts on a dashboard tab; deliver as "Make a copy" link (`/copy` at end of URL). Excel version via the xlsx skill if needed.
- **Presets/LUTs**: before/after examples per preset, install guide for mobile + desktop.
- **Swipe files/scripts**: organized by use case, fill-in-the-blank format, examples from the creator.

## Packaging
Deliver a branded PDF "access guide" (links + how to use + video walkthrough link) designed in the creator's style — the PDF is what the store delivers. Include a short Loom walkthrough. Mockups: show the template on laptop/phone screens with real content filled in.

## Licensing note
Specify personal-use license in the guide; templates are easy to share, so put value in the creator's method/guide too.
