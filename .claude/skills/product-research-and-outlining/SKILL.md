# Product research & outlining

## 1. Extract the creator's expertise (most valuable source)
Run a 45–60 min recorded interview (or async voice notes). Questions:
- What's your exact method, step by step? What do beginners get wrong?
- What did you try that failed? Your before/after story?
- Tools, numbers, routines, examples, client/follower results (with permission).
- Opinions that go against common advice (great hooks).
Transcribe; tag segments by outline section. The product must contain the creator's unique method — not generic internet advice.

## 2. External research
- Credible sources for facts/stats (studies, government/industry data, reputable publications). Record URL + date for each claim; health/finance claims need high-quality sources and disclaimers.
- Competitor products' tables of contents & 1–3★ reviews → what's missing.
- Use web search; never fabricate statistics or citations.

## 3. Transformation outline
Map **Point A (where buyer starts) → Point B (promised outcome)**, then the 4–8 milestones between. Each milestone = chapter/module.
```
Product: <name> — Promise: <outcome in timeframe>
Quick start (win in first 10 minutes)
Ch1  <milestone>: promise • key lessons • exercise/worksheet • creator story/example
Ch2  ...
Resources: templates, checklists, swipe files, tool list
Next step: upsell / community / CTA
```
Rules: one milestone per chapter; every chapter ends with an action; front-load a quick win; cut anything that doesn't move A→B; use audience language for titles.

## 4. Sizing guidance
Mini guide 10–25 pp • ebook 30–80 pp • workbook 20–60 pp (lots of fill-in space) • mini course 3–7 videos of 5–15 min • templates: 10–50 assets + a how-to guide.

## Output (`08-outline.md`)
Outline + source list + interview notes mapping. Get creator sign-off before writing.
