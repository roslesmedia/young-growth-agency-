# Online course creation

## Curriculum
From `08-outline.md`: modules = milestones; lessons = single skills (5–12 min each). Structure:
```
Welcome (what you'll achieve, how to use the course, quick win)
Module 1..n: lessons + action step + worksheet/template
Wrap-up: next steps, celebration, upsell/community
```
Mini course: 3–7 lessons total. Signature: 5–8 modules, 20–40 lessons.

## Lesson script template (creator delivers on camera)
1. Hook (what you'll be able to do after this lesson) — 15s
2. Why it matters / common mistake — 30–60s
3. Teach the steps (show screen/demo) — bulk
4. Example or creator story
5. Action step + where the worksheet is — 20s
Write in the creator's voice; bullet-point versions for creators who don't like reading scripts.

## Recording guidance for the creator
Phone or camera at eye level, window light or a ring light in front, lav mic (audio matters more than video), quiet room, 4K/1080p, film in batches, record screen with Loom/OBS/ScreenStudio for software tutorials. Short lessons are easier to film and finish.

## Assets we create (designed for this creator, no reused templates)
Slide decks (if used), lesson worksheets/workbook (workbook-planner-printables), templates/swipe files, course thumbnail per module, welcome email sequence, community prompts.

## Platform choice
| Need | Platforms |
|---|---|
| All-in-one link-in-bio + simple course | Stan Store |
| Course + community + funnels | Kajabi, Podia |
| Community-first / challenges | Skool, Circle |
| Course-focused | Teachable, Thinkific |
Check current pricing/fees before recommending.

## Completion boosters (completion → testimonials → more sales)
Quick win in lesson 1, progress tracking, drip or challenge cadence, weekly live Q&A during launch, certificate, accountability community, email nudges for inactive students.
