# Short-form video scripts

## Retention structure (15–60s)
1. **Hook (0–2s)**: visual + spoken + on-screen text all landing the same promise/curiosity.
2. **Context/stakes (2–6s)**: why it matters, for whom.
3. **Value body**: fast steps, pattern interrupts every 2–4s (cut, zoom, B-roll, text pop).
4. **Payoff**: the result/answer — deliver what the hook promised.
5. **CTA**: one action (comment keyword, follow for part 2, link in bio). Loop the ending into the start when possible.

## Formats creators can film fast
| Format | Description | Good for |
|---|---|---|
| Talking head | face to camera, punchy | authority, launch announcements |
| Voiceover + B-roll | creator records VO over clips of them working | aesthetic niches, tutorials |
| Green screen | creator reacts in front of screenshot/comment/sales page | myth busting, results, product reveal |
| Text-on-screen + trending audio | minimal speaking, strong overlay text | relatable/POV, carousels in video form |
| Tutorial/screen recording | step-by-step demo | templates, software, editing |
| Storytime | personal arc: struggle → turning point → result | trust, launch "why I made this" |
| Reply-to-comment | answer a real comment | engagement, FAQs during launch |

## Script template
```
TITLE / ANGLE:
HOOK (spoken): ...
HOOK (on-screen text): ...
VISUAL: ...
BEAT 1: line | visual | text overlay
BEAT 2: ...
PAYOFF: ...
CTA: "Comment GUIDE and I'll send you ..."
CAPTION: first line hook + value + CTA + 3–5 hashtags
SHOT LIST: A-roll setups, B-roll clips needed
LENGTH: ~30s
```
Write 3 hook variations per script (test via IG trial reels). Write in the creator's voice; keep spoken lines conversational (read aloud test).

## Launch video set (minimum)
Announcement/storytime • "what's inside" screen-scroll • problem→solution tutorial excerpt • objection answer • testimonial/results green screen • last-chance urgency.
